# 🎬 Netflix Data Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python. It uncovers insights about content types, countries, genres, directors, actors, ratings, and release trends.

---

## 🎯 Objectives
- Analyze Netflix's content library.
- Compare Movies vs TV Shows.
- Identify top countries producing Netflix content.
- Find the most frequent genres.
- Discover the top directors and actors.
- Analyze content ratings and duration.
- Visualize trends over time.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## 🔍 Key Insights
- Movies dominate the Netflix catalog.
- The United States contributes the largest amount of content.
- Drama and International Movies are among the most common genres.
- TV-MA is the most frequent content rating.
- Netflix expanded its content library rapidly after 2015.
